How the Magic Pro agent works
Three modes - each gives the agent a different level of freedom:

Automated - the action is simple and covered by a rule the team pre-approved, so the agent acts by itself and shows its work afterwards.

Confident - the agent knows what to do, but the action matters - so it proposes, explains why, and waits for your approval.

Uncertain - something rare went wrong, like conflicting data or edited dates. The agent never guesses: it steps back, shows what it found, and helps you fix it.

Pick a mode, then press any on the board.
